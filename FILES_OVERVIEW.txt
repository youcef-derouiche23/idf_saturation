ÉTAPE 1: Lire la documentation
  └─ cat QUICK_START.md
  └─ cat GUIDE_EXECUTION_COMPLET.md

ÉTAPE 2: Lancer PostgreSQL (une fois)
  └─ docker run ... postgres:15

ÉTAPE 3: Lancer le pipeline
  └─ bash start_full_pipeline.sh

ÉTAPE 4: Lancer API + Dashboard
  └─ Terminal 1: cd api && python -m uvicorn app:app --reload
  └─ Terminal 2: streamlit run dashboard/app.py

ÉTAPE 5: Accéder aux services
  └─ API Swagger: http://localhost:8000/docs
  └─ Dashboard: http://localhost:8501
